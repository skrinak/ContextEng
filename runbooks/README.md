# `runbooks/` — procedures an operator will execute again

> **Membership test**
> "A step-by-step procedure an operator will execute **again**."

Living: a runbook that no longer matches reality is worse than none, because it is followed under
pressure. The distinction from `../decisions/` is **repeat execution** — a record of one execution
freezes; a procedure that runs again is maintained.

Archetype (what a good runbook contains): https://github.com/skrinak/groundwork/blob/main/runbooks/README.md
